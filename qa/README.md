# 沉浸版邏輯 QA

在 `immersive` 目錄執行 `node qa/logic.mjs`。不需要安裝套件；結果會覆寫同目錄的 `logic-results.json`，失敗時退出碼為 1。

測試讀取當時的 `game.js`、`objects.js` 與 `template.html`，在 Node VM 中執行實際引擎與物件繪製函式。僅在記憶體中替換圖片資料並加入讀取狀態的測試入口；不修改遊戲原始碼。互動透過真實控制按鈕回呼、鍵盤與指標事件執行，計時器由測試控制。測試以 `data-control`、DOM ID、物品 ID 定位，避免簡繁改稿造成定位失敗。

## 已涵蓋

- 兩個結局均能由開場完成；衣領/鐘的先後順序及信件/屋頂鑰匙的拾取順序可交換。
- 每次點按後，背包和往事索引均無重複；解開機關後仍須拾取物品；已拾取物品不再出現。
- 錯誤插孔、錯誤物品、錯誤縫線不消耗物品；正確使用會消耗對應物品。
- 拼紙可交換後復原；離開特寫、重載後保留未完成拼紙/縫線；繼續遊戲時清除物品選取。
- 離開書桌後恢復房間圖層；先拿信後仍看得到屋頂鑰匙。
- 結局重讀往事後，返回按鈕和 Escape 都能回到結局。
- 結局約四秒（4.2 秒）的兩窗畫面過渡期間，菜單、手冊與 Escape 不打斷畫面或提前顯示尚未綁定的按鈕；不追加遊玩時間或重複結算。測試以虛擬時鐘驗證，不需要實際等待。
- 暫停/背景頁籤不累積遊玩時間；重新開始清除進度；離開頁面停止計時及音訊。
- 本機儲存被拒絕、無效 JSON、結構錯誤的存檔不妨礙開始新遊戲；完成存檔不提供續玩入口。
- 開啟標題頁後尚未按「繼續」就關閉或重新載入，不以空白狀態覆寫已載入的進度；從未開始的新訪問也不產生空存檔。
- 同一文件只呼叫一次 host completion，包括重複結局點按和本頁重新玩完；收齊往事不提早回報。
- 拖動交換、無效落點、指標取消與存檔一致性。
- 點按帶拖動功能的按鈕時不立即捕獲指標；跨過拖動門檻才捕獲。時針點按與信紙兩次點按交換仍可執行；拖動信紙跟隨指標，取消或落點無效後恢復原位。此項檢查事件處理契約，實際瀏覽器的 click 派發仍由手動驗證。
- 藍線撤回按鈕的場景座標範圍覆蓋 SVG 可見針的錨點，避免測試只按控制 ID 而漏掉圖形/熱區錯位。末孔點按可退一針；撤回不要求重新選中藍線。已走錯五孔的舊存檔可恢復、撤回、重做並完成遊戲。
- 信箱四輪支援方向鍵、累積滾輪與垂直拖動；同方向操作具有一致結果，0/9 邊界循環。涵蓋連續輸入、跨多格、半格上下的吸附門檻、拖動後 click 抑制、取消拖動，以及儲存恢復。
- 單檔 HTML 無未替換的建置變數、script/link/img 資源標籤沒有外部檔案依賴，內嵌 JavaScript 可解析。

最近一次測試結果以 `logic-results.json` 為準；報告記錄原始檔與輸出檔 SHA-256，便於辨別改稿/重建前後版本。文件體積只記資訊：使用者本輪已取消 Funtrack 上傳大小限制。

## 本測試不能證明的事

這是輕量 DOM stub，沒有瀏覽器佈局、實際音訊、系統儲存權限或外部 Funtrack 服務。通過不代表熱區幾何、手機可讀性、字型效果、畫面品質、真實音訊播放、iframe 權限與伺服器收件已驗證。單檔檢查也不是離線網路封包測試。

主代理另行手動瀏覽器驗收；其結果應另行記錄，不能當作此程式的輸出。15–20 分鐘是設計目標；解答已知的自動流程不構成盲玩時長測試，仍需首次遊玩者觀察。

## 本輪回歸問題

本套件曾重現並已回歸通過：書桌背景殘留、先拿信導致屋頂鑰匙圖像消失、結局手冊 Escape 返回軟鎖、收好結局按鈕未加入 DOM、結構錯誤存檔在手冊內崩潰。修復由主代理/音訊與字體代理接入；本 QA 不修改引擎。

藍線本輪故障的只讀定位：可見針在右側約 `(864,465)`，原撤回熱區卻在布袋下方 `(400,540)–(610,595)`；五孔走錯後不能再添加針，已穿過的孔也不能退回，因而必須碰巧找到這塊不可見的熱區。舊測試直接呼叫 `undo-stitch`，不能發現錯位。新增的場景座標契約可防這類具體錯位；它仍不能代替實機畫面縮放、遮擋與觸控大小的檢查。最新修復是否通過，以本次 `logic-results.json` 結果為準。
